# SecureLLMBench dashboard

Phase 12 React/TypeScript evidence browser. See [the Phase 12 implementation notes](../docs/DASHBOARD_PHASE12_IMPLEMENTATION.md) for the actual API contract, scientific-integrity constraints, and commands.

Use `npm run dev` for local development and `npm run build` for the production bundle. Native `fetch` is used deliberately; no data is substituted if a real API request fails.
