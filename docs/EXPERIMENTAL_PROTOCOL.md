# Controlled experiment protocol and current execution gate

Before execution, freeze a dataset source and checksum, eligible case list, target-model identities, attack families/order, repetitions, seeds, generation settings, measurement versions, outcomes rubric, analysis plan, and related-prompt grouping. Store the locked protocol and any later amendment as separate append-only records. The controlled CLI now requires `--dataset-source`, `--protocol-lock`, and `--max-calls`: it verifies source bytes and exact case content, a locally frozen specification hash, installed model digests, and call budget before inference. A local lock does **not** establish external preregistration or scientific eligibility.

Run `scripts/run_controlled_experiment.py` with a versioned specification and an output directory. It checks already-installed Ollama models, records baselines, fresh isolated attacks, sequential attacks with history, recovery probes, and optional matched benign turns/probes, then saves immutable observations and a manifest. Repetitions are explicit in the specification. Failed calls remain failed observations. Resume uses deterministic IDs; overwriting an existing observation is rejected. Benign-turn count matching is implemented, but content equivalence and valid behavioral measurement still require independent review before recovery or causal claims.

After execution, use `scripts/build_annotation_candidates.py` with independently declared case objectives, then `scripts/annotation_batch.py` to randomize and blind raters. Collect two independent judgments and adjudicate disagreements. Compare an automated evaluator on disjoint grouped development, validation, and held-out test splits; `core/evaluation/split_integrity.py` rejects declared related groups crossing splits. This cannot detect unreported semantic near duplicates. Run metric analysis only on eligible, version-compatible observations with explicit missingness and exclusion counts. Preserve source files, hashes, output manifests, environment versions, and all failed observations.

No Phase 1 multi-model, independently labeled controlled study has been completed in this repository. The three-case showcase and synthetic test fixtures cannot stand in for it.
