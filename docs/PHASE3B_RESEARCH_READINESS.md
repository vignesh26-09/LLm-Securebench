# Phase 3B research-readiness decision

**Decision on 10 October 2026: engineering workflow demonstrated; controlled empirical safety study not ready for confirmatory claims.** The 50-call pilot is real local inference on a synthetic harmless task. It is not evidence that one model is safer, that a jailbreak succeeded, or that BSDA/RC/SAEA distinguish safety behavior. The historical JailbreakBench judge calibration is a separate, genuine negative evaluator-reliability result.

| Gate | Evidence now | Decision |
|---|---|---|
| Executable controlled conditions | Fresh baseline; isolated A/B/C; two orders; matched benign lane; attacked and benign probes; 50 persisted pilot responses. | Engineering gate passed. |
| Source/protocol integrity | Dataset/specification/local-lock SHA-256 verified before calls; immutable observation IDs and manifest hashes; separate pilot DB. | Engineering gate passed. Local freeze is not external preregistration. |
| Research attack dataset | No approved versioned target-execution selection, objectives, family labels, related-group split manifest, or review of imported attack rights. | Blocked. Historical judge-comparison rows are not target cases. |
| Human attack-outcome reference | Blinded two-rater/adjudication workflow exists and has synthetic tests, but no genuine Phase 3B labels. | Blocked; ASR scientific denominator absent. |
| Automated evaluator | Historical Gemma stance mapping has 135 false positives among 295 usable rows and κ≈0.211; no held-out target-domain validation. | Ineligible as sole outcome truth. |
| Behavioral states and calibration | BSDA/RC/SAEA implementations and guards exist; no independently validated representations or applicable calibration for new target responses. | Blocked; preserve null/undefined values. |
| Isolation/context certainty | All pilot requests sent complete ordered histories and report within declared context window; canary disabled; 12 isolation records unverifiable by provider. | No verified isolation or attention claim. |
| Inferential design | Candidate grouped/paired plan exists, but N/precision, primary contrasts, multiplicity, rater capacity, and claim-specific evaluator error bounds are not frozen. | No confirmatory estimate or ranking. |
| Publication charts | Real historical calibration figure remains eligible. Pilot metric chart queries return `insufficient_data`. | No new scientific result figure. |

Next scientific work is to review a legitimately accessed benchmark source and exact license/revision, freeze case objectives and grouped splits, validate the human rubric on real responses with independent raters, develop/validate behavioral-state measurement and calibration, then lock a new production protocol before collection. Decide the sample size and statistical precision from development evidence and resources rather than pilot response direction. If an automated evaluator fails claim-specific held-out validation, report human-labeled outcomes and keep automated conclusions blocked. The present project can support a methods/research-software report and an honest calibration negative result; RQ1–RQ5 empirical safety conclusions remain unavailable.

The publication chart API currently supports judge calibration, BSDA distribution, recovery distribution, SAEA deviation, and applicability summary. A study-ready ASR-by-model chart, paired-effect interval chart, attack-order interaction chart, and evaluator-sensitivity chart remain unavailable because no eligible Phase 3B human-labeled dataset or frozen inferential analysis exists; they were not replaced with synthetic figures. Human annotation imports also require an explicit scientific-review/promotion path before the paper-chart provenance gate can admit them.
