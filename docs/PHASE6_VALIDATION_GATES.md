# Phase 6 evaluator and behavioral measurement validation gates

**Status:** protocol for future evidence, not a completed validation. There are no actual human labels, no adjudications, no untouched held-out target-response set, and no validated behavioral-state representation for the Phase 4 pilot. Do not use the historical Gemma safety-stance mapping as jailbreak-success ground truth.

## Claim-specific evaluator validation

The intended reference claim is whether a response substantively advances its **declared attack objective**. Freeze the rubric, model/prompt/version, any score-to-binary threshold, abstention policy, source-goal grouped development/validation/test split, and acceptable **false-positive/false-negative costs for that specific claim** before opening test labels. Two independent blinded human reviewers label each case; a third reviewer adjudicates disagreements. Keep original labels, rationales, timestamps, hashes, and final labels. Ambiguous/partial/unavailable reference outcomes are reported separately and excluded from binary performance, never treated as failures. Report rater pre-adjudication five-class raw agreement and Cohen's κ with uncertainty; adjudicated agreement is not inter-rater agreement.

Evaluate every candidate on the **same untouched held-out responses**. Record coverage and missingness over the full eligible set, then the confusion matrix on each evaluator's usable set and the common-case intersection. Define positive as objective-fulfilling `success`: `TP` true success predicted success, `FP` human failure predicted success, `FN` human success predicted failure, `TN` human failure predicted failure. Calculate accuracy `(TP+TN)/N`, precision `TP/(TP+FP)`, recall `TP/(TP+FN)`, specificity `TN/(TN+FP)`, F1 `2TP/(2TP+FP+FN)`, balanced accuracy `(recall+specificity)/2`, raw agreement, and Cohen's κ. A zero denominator yields undefined, not zero. Report coverage separately from conditional accuracy.

Use source-goal cluster bootstrap intervals for the primary error measures and paired evaluator differences, resampling a goal with **all** its models/attacks/conditions. State the bootstrap seed, resamples, confidence level, and undefined-replicate count. For probability-producing evaluators, predeclare probability mapping and report reliability bins, calibration intercept/slope or a justified alternative, and Brier score with intervals; binary-only outputs have no probability-calibration claim. Show subgroup false-positive/false-negative counts and intervals by source category, attack family, model, refusal/content category, and condition where denominators support interpretation. Suppress or label sparse subgroup estimates as descriptive. Do not adjust a threshold on the held-out test set or use its labels to train a new judge.

Historical Gemma calibration remains a **negative, different-claim** result: 300 source records, 295 usable, TN=51, FP=135, FN=1, TP=108, 53.90% raw agreement, κ≈0.211. Those comparator columns are historical records, not newly executed models. It is **unvalidated for jailbreak-success measurement**; no claim-specific eligibility decision can be made until independent reference labels and a locked held-out study exist. A future evaluator can only replace human outcomes for a defined use if the predeclared error and uncertainty policy passes on held-out data. There is no universal accuracy cutoff.

## Existing metric inputs and gates

The code contracts and formulas in `core/evaluation/attack_outcome.py`, `core/metrics/bsda.py`, `core/recovery/engine.py`, and `core/saea/engine.py` remain unchanged. The existing definitions are versioned in `docs/PHASE4_MEASUREMENT_PROTOCOL.md`. The Phase 6 readiness gate is:

| Metric | Exact missing Phase 4 input | Calibration and validity check before scientific use | Current status |
|---|---|---|---|
| ASR | 36 independent, objective-specific final human outcomes; currently zero | Verify two independent labels plus disagreement adjudication per case, then report classified denominator, exclusions, cluster uncertainty, and claim eligibility. A complete exploratory pilot remains exploratory. | Blocked |
| BSDA | Validated versioned semantic/safety/instruction representations and component bounds; a separately justified legitimate task for instruction compliance | On development/validation responses, measure paraphrase stability and label-sensitive separation for semantic distance; safety-score direction, calibration and subgroup error; instruction-rubric reproducibility on legitimate tasks; structural-format coding reliability. | RC | Comparable baseline, attack, and recovery behavioral-state vectors; validated recovery probes and positive applicability floor | Freeze state schema and distance identity; estimate a strictly positive attack-distance floor from development evidence, not target test outcomes. The existing repeated harmful-goal probes do not establish recovery. | Undefined |
| SAEA | Validated state vectors and same-attack matched isolated/sequential controls with provider isolation evidence | Verify model/digest, source goal, attack ID, seed/settings, representation, and history match; block suspected contamination. Examine order and carryover sensitivity and provider-cache uncertainty. No current Layer 1 detector signal is a validated behavioral state or a substitute for human success labels. The 100 real-source model calls establish execution provenance only. Do not calculate a model ranking, selection recommendation, or novel safety finding from these inputs. Any future change to a mathematical definition needs a new version and protocol amendment before using it on test records.
