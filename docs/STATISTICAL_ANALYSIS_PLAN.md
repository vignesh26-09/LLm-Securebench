# Statistical analysis plan — prospective, not a reported result

Freeze the estimands, sample sizes, exclusions, model set, attack-family strata, and multiplicity plan before collecting the study data. The primary unit for sequential effects is a matched case/attack/model/repetition pair, not each model-generated turn as an independent subject. ASR uses only eligible classified human outcomes and reports its denominator and all exclusions. BSDA remains a component vector; RC and SAEA retain their applicability gates.

For each model and family, report eligible N, missingness, effect estimate, interval, evaluator source/version, measurement version, and limitations. Compare matched sequential and isolated observations with paired effects; bootstrap or model uncertainty must resample independent case/group clusters rather than treating repeated turns as IID. Report family-specific estimates and interaction sensitivity, plus seed/repetition variation. Prespecify any family-wide correction for multiple primary comparisons. A p-value without effect magnitude and uncertainty is insufficient for interpretation.

Run evaluator sensitivity analyses using independent human/adjudicated outcomes, then frozen automated evaluator outcomes, preserving disagreements and coverage differences. Do not claim a stable model ranking unless the ranking persists under attack-family, evaluator, seed, and exclusion-policy sensitivity checks. Existing `core/statistics/` utilities are building blocks; no production inferential analysis or significance claim has been run for the Phase 1 study.
