# Terminology Audit

## Canonical terms for the paper

| Term | Canonical expansion and permitted description |
|---|---|
| Layer 1 | Detector-level engineering observations; not ground truth. |
| Layer 2 | Structured measurement layer; current local dashboard availability is zero. |
| BSDA | Behavior Stability Detection Algorithm; four components, no validated composite. |
| RC | Recovery Capability; raw, calibration-dependent trajectory. |
| SAEA | Sequential Attack Evaluation Algorithm; CV_obs is observed cumulative vulnerability, not ASR. |
| DRAA | Dynamic Risk Assessment Algorithm; Modes A/B diagnostic and uncalibrated; Mode C unavailable. |
| PRI | Prompt Robustness Index; profile only, with no validated scalar grade or ranking. |
| DQI | Dataset Quality Index; exploratory measurement. |
| Judge calibration | Comparison against recorded human outcomes under the fixed predeclared mapping; not human replacement validation. |

## Wording rules

Use “observed,” “recorded,” “implemented,” “exploratory,” “uncalibrated,” or
“engineering demonstration” where applicable. Reserve “validated” for the
specific status documented in the evidence bundle. Do not use “risk score,”
“safety score,” “ASR,” “ground truth,” “prediction,” “ranking,” “winner,” or
“human-equivalent” for current outputs.

## Audit result

The paper-facing evidence documents and table/figure artifacts use consistent
expansions for BSDA, SAEA, DRAA, PRI, DQI, and RC. No contradictory expansion
was found in the reviewed evidence bundle. Historical implementation notes are
not authoritative paper sources and should not override this vocabulary.
