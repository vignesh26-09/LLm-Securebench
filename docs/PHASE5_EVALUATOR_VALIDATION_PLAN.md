# Phase 5 held-out evaluator validation plan

The existing historical Gemma 3:4B **safety-stance** mapping had 300 JailbreakBench source records, 295 usable, TN=51, FP=135, FN=1, TP=108, 53.90% raw agreement, and Cohen's κ≈0.211 against the source human majority. It is not an attack-success reference. The official JailbreakBench comparator columns in that historical CSV are stored predictions from the source dataset, not new executions in this repository. The comparison in `docs/PHASE3A_EVALUATOR_COMPARISON.md` is exploratory because no held-out split was declared there. Do not recycle the historical 300 rows as fresh Phase 5 target responses or human labels.

Before any new comparison, freeze the target claim (attack-objective fulfillment, not generic refusal/safety stance), rater rubric, score-to-label mapping if an evaluator yields a continuous score, model/prompt versions, and grouped development/validation/test split. Group by source goal and all attack variants; screen duplicate and near-duplicate goals and the historical calibration source. Use development rows only for prompt/mapping design, validation rows for any threshold or eligibility policy, and the untouched test rows once for final estimates. The current two-case exploratory pilot cannot be a meaningful held-out test set, and its responses are already visible in the workflow.

On each same held-out target response, obtain two independent human judgments and adjudicate disagreements before using the reference outcome. Run the historical Gemma mapping as a **fresh, version-pinned** comparator if feasible, and one or more official, legally usable objective-aligned baselines under recorded settings. Candidate official implementations are JailbreakBench's classifier and StrongREJECT, subject to their distinct rubrics, licenses/constituent rights, model availability, and hardware/API constraints. No paid service or large weights are automatically invoked. If an implementation cannot run locally, report it as unavailable rather than substituting a different model. If external predictions are imported, require exact sample IDs, model/rubric versions, source hashes, generation provenance, and an explicit predeclared mapping. Stored historical comparator columns remain historical context only.

For every evaluator report coverage and failure reasons on all eligible samples, then accuracy, precision, recall, specificity, F1, balanced accuracy, raw agreement, Cohen's κ, and the full confusion matrix on common usable cases. Use goal-group bootstrap confidence intervals and subgroup results by attack family, source category, model, and refusal/content category where adequately populated; do not treat repeated variants as independent. Show results on each evaluator's own usable set **and** the common-case intersection so coverage cannot be hidden. Report disagreement examples only with controlled content handling. Compare automated errors against the exact scientific use: a false-positive-prone judge cannot be the sole truth for ASR or model ranking. Eligibility requires a policy locked before test inspection, with claim-specific acceptable error and uncertainty; there is no universal accuracy cutoff to retrofit after seeing results.

With zero actual Phase 5 human labels and no frozen held-out test split, all new evaluator performance and eligibility decisions are **pending**. The old κ≈0.211 remains a real historical negative calibration result only.
