## Gaps and handoff boundaries

The existing system can provide provider-neutral conversation I/O, source/identity hashes, immutable historical observations, request-history/canary evidence, generic pairing/resampling, scientific-record persistence and provenance-filtered charts. None is already the approved feasibility pilot. Before any new implementation, the plan still requires its literature gate; later component decisions must specify restricted secret storage, exact retry and failed-turn semantics, provider/template evidence, approved probes/goals, numeric matching tolerances, seven-arm applicability, context status and a calculated execution budget. Actual model calls remain separately authorized.

**Open Phase 0 unknowns:** current installed model digest and template rendering; provider-effective top-p/role priority/context retention; empirical validity of behavioral scorers and calibration artifacts; complete provenance of the main database's other scientific-record families; and full per-observation cryptographic re-verification of historical pilots. These do not alter the source-level metric equations or make any historical artifact eligible for this new estimand. They are recorded rather than inferred away.
