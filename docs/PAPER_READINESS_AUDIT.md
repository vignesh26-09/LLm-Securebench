# Paper readiness audit — 10 October 2026

**Decision:** Suitable to describe as a research-software prototype and evidence-control methodology. Not ready to report the proposed RQ1–RQ5 empirical findings or a model-safety ranking. This audit is a software assessment, not conference acceptance advice.

The backend has a controlled observation runner, explicit experimental identities, canary/contamination evidence, immutable scientific records, null-preserving BSDA/RC/SAEA contracts, a real judge-comparison artifact, and provenance-gated charts. Phase 2 adds a source-hashed human annotation transport, independent/adjudicated label import, a structured automated outcome record, split-integrity checking, and specificity/balanced-accuracy diagnostics. The full Python suite is the software regression gate; fixture tests do not constitute experimental validation.

**Real empirical evidence currently available:** JailbreakBench judge comparison, 300 source / 295 usable, 53.9% agreement, κ≈0.211. Its low agreement is a negative evaluator-reliability finding under a recorded mapping. The three-case local runs are engineering demonstrations. There are no qualifying Phase 1 BSDA, RC, or SAEA results and no independent human-labeled multi-model study. The chart gate correctly returns `insufficient_data` for those research plots.

**Blocking work for the proposed empirical paper:** approved versioned dataset with verified source hash; locked preregistration; matched benign conversation controls; validated behavioral-state measurement; repeated runs across multiple models; independent human labels with rater agreement; leakage-reviewed held-out evaluator validation; grouped paired inference and uncertainty; sensitivity to attack family/order/seed/evaluator; and reproducible artifacts with publication review. These are research activities, not values that code or a fixture can supply.

**Paper outline:** Abstract (scope and actual evidence); Introduction (problem); Related Work (verified sources); Threat Model; Methodology (conditions, versions, gates); Evaluator Validation (real negative calibration and planned held-out study); Experimental Setup (only executed runs); Results (only real eligible data); Ablation Study (only when run); Limitations; Conclusion. No numeric BSDA/RC/SAEA table, novelty-of-findings claim, causal synergy claim, or model recommendation is presently supported.
